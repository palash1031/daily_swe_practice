## Setup

You need JDK 17 or newer. `lib/` in this folder holds JUnit 4.13.2 and Hamcrest 1.3. Every Java exercise's run scripts use them, so no build tool is needed. Each exercise also has a `pom.xml` if you'd rather open it in IntelliJ or run it with Maven.

For how the exercises work and how they're graded, see the [main README](../README.md).
